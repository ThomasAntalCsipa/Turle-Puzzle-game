Double click the .exe file and drag the black background window (treminal)
to the side of the moinotrs edge so it resizes and snaps in to place.
Then click inside of the terminal window.

You controll the player with wasd where you have to
write w, a, s or d and press enter before the next command.
Just don't write ^Z with ctrl + z

If you close the game window (not the terminal) the next
valid comand will crash the game.
